# Jayabharathi Bakery Website

A single-page static website for Jayabharathi Bakery, Thalassery.

## Preview locally

Open `index.html` in a web browser. Keep `jayabharathi-logo.png` beside it; the bakery photos are embedded in the HTML file.

## Publish with GitHub Pages

Upload these files to the root of a GitHub repository. In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The stock bakery photos are illustrative and should be replaced with the bakery's own images before final publication.
